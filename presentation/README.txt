INDUSTRIAL ASSET GRAPH — INTERACTIVE NARRATED SHORT FILM

HOW TO RUN ON WINDOWS
1. Unzip this folder.
2. Double-click START_PRESENTATION.bat
   — or simply open index.html in Edge/Chrome.
3. Click START FILM. Browsers require a click before spoken narration can begin.

WHAT IT DOES
- Uses the same veteran-electrician presenter scenes created for the project.
- Narrates the full presentation with your browser's built-in speech engine.
- Automatically selects a deeper English male voice when available.
- Provides a voice selector so you can choose any installed browser/system voice.
- Cinematic slow zoom / pan, scan-light effect, fades, captions, and chapter navigation.
- Final interactive terminal commands: Risk, Map, Trace, Verify, Help.
- Fullscreen button included.

VOICE NOTE
The voice is generated live by the browser (Web Speech API), not a prerecorded voice actor.
Voice names differ by computer. On Windows/Edge, natural Microsoft voices are often available.
For a more veteran-tradesman sound, try a male voice such as Guy, Christopher, Mark, David, or another Natural/Online male voice if listed.
