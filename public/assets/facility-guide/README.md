# Facility Guide assets

`guide-idle.png` is the supplied still-image fallback currently used by the guide.

For true character motion, add transparent assets here using these names: `guide-idle.webm`, `guide-enter.webm`, `guide-talk.webm`, `guide-point.webm`, `guide-warning.webm`, `guide-success.webm`, `guide-exit.webm`, and `guide-sleep.webm`. Keep the PNG fallback; the UI must remain usable when motion files are unavailable.
