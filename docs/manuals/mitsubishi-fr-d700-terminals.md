# Mitsubishi FR-D700 — terminal legend (catalog example)

**Not installed at J. Lieb Foods.** This excerpt exists so a swapped brand of speed control can be read: numbered silks **1 / 2 / 3** do not match PowerFlex **A1 / AC**.

## Analog speed reference

| Silk | Meaning |
|---|---|
| **1** | Analog positive — frequency setting input (typical 0–5 V). |
| **2** | Analog common for terminal 1. |
| **5** | Frequency-setting common / analog 0 V (book naming). |
| **3** | Analog negative / shield return when the book calls it out. |

If you grab a Mitsubishi (or similar numbered) VFD instead of a PowerFlex, look up **1 = analog positive** in this book — do not assume A1. No plant `FEEDS` wiring is inferred from this catalog.
