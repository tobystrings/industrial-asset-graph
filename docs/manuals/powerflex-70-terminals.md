# PowerFlex 70 — terminal legend (catalog excerpt)

This is a **public catalog excerpt** for the Allen-Bradley PowerFlex 70 on FG-L4-MTN-001. It is **not** the PowerFlex 4 booklet. Field destinations stay `FIELD_VERIFY`.

## Analog speed reference

| Silk | Meaning |
|---|---|
| **A1** | Analog input 1. Frequency reference. |
| **AC** | Analog common. |

PowerFlex 70 parameter numbers are **140 / 141** (accel / decel), not A051 / A052.

When the drive faults, do not invent a plant motor or a restart sequence. Reconnect only recorded terminals after the destination is verified.

## Manual status

This excerpt is the in-app PF70 book. The PowerFlex 4 path is a different family.
