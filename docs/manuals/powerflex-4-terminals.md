# PowerFlex 4 — terminal legend (catalog excerpt)

This is a **public catalog excerpt** for the Allen-Bradley PowerFlex 4 family already indexed on Line 2. It is not a bundled OEM PDF. Field destinations stay `FIELD_VERIFY`.

## Analog speed reference

| Silk | Meaning |
|---|---|
| **A1** | Analog input 1. Typical 0–10 V frequency reference. |
| **AC** | Analog common for A1. |
| **A2** | Analog input 2 (0–20 mA) when used. |

When the drive faults, reconnect the speed-reference pair **A1 / AC** only after the destination is verified in the field. This excerpt does not name a plant motor or conveyor.
