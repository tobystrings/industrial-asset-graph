# Line 2 Cabinet — Visual References

The project includes an approved cabinet reference render and a matching interactive engineering drawing.

- Reference render: `public/assets/line2/control-cabinet/photos/cabinet_reference_render.png`
- Interactive drawing: `public/assets/line2/control-cabinet/cabinet.svg`
- Printable drawing: `public/assets/line2/control-cabinet/cabinet.pdf`
